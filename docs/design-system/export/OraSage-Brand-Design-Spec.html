图形标：带缺口的圆环 + 中心一点。缺口 = Oracle（东北 45°，紫气东来）；中心点 = Sage。圆环同时是字母 O。

字标：OraSage，思源宋体 SemiBold，字距 0.08em。中文名 海棠未眠 同一套宋体，字距 0.12em。顶栏只用拉丁字标；中文名用于署名、品牌页、报告封面。符号位只用图形。组合锁定仅限正式署名场合。

7. 图像与印刷

  • 插画：单色墨线描，至多一处朱砂点睛；禁止面性扁平 / 3D。
  • 商品摄影：纸色背景、自然侧光、留白 ≥40%。
  • 印刷：未涂布自然白；墨用四色黑或单黑；朱砂近似 C0 M62 Y69 K35。工艺白名单：单色、朱砂专色、压凹、局部 UV。禁止烫金、镭射、渐变堆叠。
